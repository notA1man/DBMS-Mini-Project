Self-hosted variable fonts (SIL Open Font License 1.1), latin subset, from Fontsource:

- `archivo-var.woff2` — Archivo, axes wght 100–900 + wdth 62–125
- `jetbrains-mono-var.woff2` — JetBrains Mono, axis wght 100–800

Loaded through `next/font/local` in `src/app/layout.tsx`, so builds don't depend on reaching Google Fonts.
